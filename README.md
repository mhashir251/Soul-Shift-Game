# Soul Shift

### A 2D Puzzle-Platformer Game

**Course:** CSC241 – Object Oriented Programming  
**Class:** BEE-3A  
**Instructor:** Dr. Riaz Hussain

## Project Overview

Soul Shift is a 2D puzzle-platformer developed using C++ and SFML. The player can switch between Human and Ghost forms, each having distinct abilities to overcome obstacles and solve puzzles.

## Technologies Used
- C++17
- SFML 2.6.2
- CMake
- Git and GitHub

## Implemented Components
- Game
- GameObject
- Character
- Human
- Ghost
- Obstacle
- Switch
- Door

## Object-Oriented Programming Concepts
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
